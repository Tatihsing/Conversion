# 會議記錄工具箱 v2.0

**錄音檔 → 全自動產出 HTML 會議記錄 + Word 可編輯版**

零安裝、可攜帶，複製資料夾到任何 Windows 電腦即可使用。

---

## 快速開始（3 步驟）

### 1. 設定 API Key（僅功能 1、2 需要）

用記事本開啟 `api_keys.txt`，每行貼入一組 Gemini API Key：

```
AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
AIzaSyYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYY
```

> **申請方式**：前往 https://aistudio.google.com/apikey → 點選「Create API Key」→ 複製  
> 建議用 3~5 個 Google 帳號各申請一組，全部免費

### 2. 雙擊 `啟動.bat`（或 `start.bat`）

首次啟動會自動下載 Python 環境（約 25 MB），之後直接進入選單。  
如果 `啟動.bat` 無法執行，請改用 `start.bat`（功能完全相同）。

> 💡 **懶人用法**：也可以直接把錄音檔（MP3）或逐字稿（TXT）**拖曳到 bat 檔上**，  
> 會自動跳過選單，直接執行全自動會議記錄。

### 3. 選擇功能 → 選擇檔案 → 完成

```
══════════════════════════════════════════════════════
  會議記錄工具箱 v2.0
══════════════════════════════════════════════════════

  [1]  全自動會議記錄  （錄音/逐字稿 → HTML + Word）
  [2]  純轉逐字稿      （錄音 → 文字稿，使用 Gemini）
  [3]  離線轉逐字稿    （錄音 → 文字稿，不需網路）
  [4]  產生 SRT 字幕   （影音 → SRT 字幕檔）
```

## 功能說明

| 功能 | 說明 | 需要 API Key | 需要網路 |
|------|------|:---:|:---:|
| **[1] 全自動會議記錄** | 錄音或逐字稿 → HTML 儀表板 + Word 可編輯版 + PDF | ✅ | ✅ |
| **[2] 純轉逐字稿** | 錄音 → 繁體中文文字稿（雲端 Gemini） | ✅ | ✅ |
| **[3] 離線轉逐字稿** | 錄音 → 文字稿（本機 faster-whisper，不需網路） | ❌ | ❌ |
| **[4] 產生 SRT 字幕** | 影音 → SRT 字幕檔（本機 faster-whisper） | ❌ | ❌ |

### 功能 [1] 產出檔案

- **HTML**：上半部為 AI 分析的卡片化儀表板摘要，下半部為詳細內文整理
- **Word (.docx)**：詳細內文的可編輯版本，方便修改後發送
- **PDF**：自動透過 Chrome 轉換（需已安裝 Chrome）

1. 把整個 `meeting-auto` 資料夾複製過去（USB、網路芳鄰皆可）

3. 首次會自動下載 Python 環境（需要網路，約 1~2 分鐘）

**不需要安裝 Python、不需要管理員權限、不會動到系統設定。**

## 常見問題

**Q：首次啟動失敗？**  
A：確認有網路連線，Windows 10 以上版本。

**Q：出現 API Key 錯誤？**  
A：用記事本編輯 `api_keys.txt`，確認 Key 正確且無多餘空格。

**Q：HTML 產出了但沒有 PDF？**  
A：用 Chrome 開啟 HTML 檔案，按 Ctrl+P，印表機選「另存為 PDF」。

**Q：轉錄品質不佳？**  
A：在 `glossary.xlsx` 補充對照表，下次自動修正。

**Q：模型找不到（404 錯誤）？**  
A：編輯 `core/shared.py`，將 MODEL_AUDIO / MODEL_TEXT 改為最新版本。  
可至 https://ai.google.dev/gemini-api/docs/models 查詢。
