零安裝、可攜帶，複製資料夾到任何 Windows 電腦即可使用，包含自動更新與依賴修復機制。

## 快速開始（3 步驟）

### 1. 設定 API Key（僅功能 1、2 需要）

用記事本開啟 `api_keys.txt`，每行貼入一組 Gemini API Key：

```
AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
AIzaSyYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYY
```

> **申請方式**：前往 https://aistudio.google.com/apikey → 點選「Create API Key」→ 複製  
> 建議用 3~5 個 Google 帳號各申請一組，全部免費

### 2. 雙擊 `啟動.bat`（或 `start.bat`）

首次啟動會自動下載 Python 環境（約 25 MB），之後直接進入選單。  
如果 `啟動.bat` 無法執行，請改用 `start.bat`（功能完全相同）。

> 💡 **懶人用法**：也可以直接把錄音檔（MP3）或逐字稿（TXT）**拖曳到 bat 檔上**，  
> 會自動跳過選單，直接執行全自動會議記錄。

### 3. 選擇功能 → 選擇檔案 → 完成

```

## 常見問題

**Q：首次啟動失敗？**
A：確認有網路連線，Windows 10 以上版本。

**Q：出現 API Key 錯誤？**
A：用記事本編輯 `api_keys.txt`，確認 Key 正確且無多餘空格。

**Q：HTML 產出了但沒有 PDF？**
A：用 Chrome 開啟 HTML 檔案，按 Ctrl+P，印表機選「另存為 PDF」。

**Q：轉錄品質不佳？**
A：在 `glossary.xlsx` 補充對照表，下次自動修正。

**Q：模型找不到（404 錯誤）？**
A：編輯 `core/shared.py`，將 MODEL_AUDIO / MODEL_TEXT 改為最新版本。
可至 https://ai.google.dev/gemini-api/docs/models 查詢。

## 雲端備份與自動化架構 (v2.2.x 更新)

### Google Drive 自動上傳功能
- **認證方式 (OAuth 2.0)**：為突破 Google 服務帳戶 0 容量的限制，本專案已全面改用 OAuth 使用者授權。首次執行時會開啟瀏覽器讓您登入，隨後產生 `token.json` 即可無限期背景自動上傳。
- **資安最佳實踐（分身隔離法）**：建議建立一個「機器人分身帳號 (B)」。用您的本尊帳號 (A) 建立資料夾並共用給 (B)，然後讓程式使用 (B) 帳號進行授權。萬一 `token.json` 外流，駭客也只能存取 (B) 帳號的該資料夾，完美保護本尊帳號的私密資料。
- **資料夾架構**：雲端存放路徑採三層架構：`[指定總資料夾] -> [上傳日期_使用者名稱] -> [原始錄音檔名稱]`。若重新執行相同錄音檔，程式會自動「覆蓋更新」雲端檔案，避免產生重複檔案。

### 穩定性與防呆機制
- **API Key 自動輪換與淘汰**：若偵測到 Gemini API Key 限流，會無縫切換下一組；若偵測到 Key **已過期或外洩 (403 Leaked)**，會直接將其從記憶體中永久剔除並重試，徹底防止程式崩潰。
- **100% 可攜帶環境**：新增免 Git 的 ZIP 自動更新機制。若偵測到缺少 `ffmpeg` 等底層工具，也會自動從 GitHub 下載免安裝版，確保將資料夾丟到任何一台空機上都能一鍵運行。
- **原生中文介面**：全面棄用 .NET WPF 舊版檔案選擇器，改用純 Python `ctypes` 呼叫 Windows 底層原生 API，確保在各種環境下都能完美渲染出與系統語言 (繁體中文) 完全一致的現代化選擇視窗。
```
